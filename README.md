# Responsive Login Form with SASS

This is a responsive login form built using HTML, CSS, and SASS. 
The project follows a structured SASS architecture (e.g., using partials like `_variables.scss`, `_mixins.scss`, etc.) to organize styles efficiently and make maintenance easier.

## 💻 Technologies Used
- HTML5
- SASS (SCSS syntax)
- CSS3

## 📱 Features
- Responsive design for all screen sizes
- Clean and minimalistic UI
- SASS modular structure
